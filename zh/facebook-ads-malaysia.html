讲白一点

在马来西亚，大部分 FB 广告账户表现差，问题不在受众，在追踪。 Pixel 或 Conversions API 没装好，Meta 就往错的方向优化 — 受众和素材怎么调都没用。

接手一个账户就四步：先审计，先修追踪，好的广告继续跑、新的在旁边搭，然后每周测素材。第一天就全部暂停？那是最贵的错误。

合理预期：做对的话，30–90 天内潜在客户成本（CPL）降 30–56%。每月广告费至少 RM1,500–2,000 才跑得动。

账户为什么表现差

问题几乎
不在受众。

审计过 B2B、美容、餐饮、零售、医疗的账户之后，来来去去就是这四个问题。

1. 追踪坏了

没装 Pixel、装一半、或没接 CAPI。转化记录不到，Meta 就找不到你的买家。这是最常见的问题，没修好之前，其他都白做。

2. 钱都拿去 Boost Post

Boost 买到的是互动，不是询问。账户花了几个月的钱，算法却没学到谁会买。

3. 学习阶段一直重置

一直改、一直重开，账户永远毕不了业 — 卡在学习阶段的 RM3,000 账户，输给稳定跑的 RM1,500 账户。

4. 素材疲劳

同一条广告跑太久：频次往上，点击往下。不是"FB 没用了"，是大家看腻了。

接手流程

四步。
追踪先。

接手的四个步骤

第一步 — 先审计。账户结构、Pixel 和 CAPI、转化事件、归因、素材历史、过去 90 天的花费和结果。先搞清楚为什么差，再动手。

第二步 — 先修追踪，再花钱。Pixel 和 CAPI 没修好之前，一分新预算都不投。转化事件也重新定义在真正有用的动作上 — 一段 WhatsApp 对话、一个预约。

第三步 — 好的留着，新的旁边搭。换代理最常见的错误就是第一天全部暂停，等于把账户学到的东西全丢掉。有效的广告组照跑，新结构在旁边建好、跑出学习阶段之后，预算才慢慢搬过去。

第四步 — 每周优化。每周测素材，该停的停、该加的加，预算往赢家放。每周用白话汇报：现在一个询问 X 块，之前 Y 块，因为 Z。数字都公开在 实时成果看板。
